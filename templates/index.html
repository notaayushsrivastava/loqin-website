Features

What does Loqin really do?

Switch through the key experiences: automation, security, tray control, and the setup flow.

Automation that stays out of the way

Loqin checks the connection at regular intervals and re-authenticates when the session drops, so the app can do its job while you keep working.

Background pinging Monitors connectivity silently
Instant recovery Reconnects without opening the portal manually

Security built around native Windows tools

Credentials are stored through the OS credential system with the keyring library, keeping the login experience simple and local.

Native storage Uses Windows Credential Manager
Focused permissions Only what the app needs to connect

Tray-first controls for daily use

The app runs discreetly beside the clock, with quick actions for status, speed graph access, reconnecting, pausing, and settings.

Quick menu Connect, pause, resume, and exit from one place
Performance mode Connects to the best BSSID on the network

Easy installation and startup setup

The installer asks for registration details up front and can launch automatically when Windows starts.

Wizard-based install Enter credentials during setup
Auto-start option Launches on boot when enabled
