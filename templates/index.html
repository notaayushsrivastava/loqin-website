Features

What does Loqin really do?

Explore how Loqin automates Wi-Fi authentication, keeps credentials safe on your device, and stays out of your way.

Automation that stays out of the way

Loqin checks the hostel network at regular intervals and instantly re-authenticates when the captive portal drops, so your work and downloads proceed without manual intervention.

Background pinging Monitors connectivity silently with minimal CPU/battery impact
Instant recovery Reconnects without repeatedly opening the captive portal browser tab

Security built around native OS vaults

Credentials never leave your machine. Loqin leverages native OS security mechanisms via the Python keyring library.

Native OS storage Uses Windows Credential Manager on Windows and Apple Keychain on macOS
Zero external tracking No telemetry, tracking, or external server credential routing

Discreet desktop controls for daily use

Loqin runs quietly in the Windows notification area (beside the clock) or the macOS menu bar, giving you instant one-click controls.

Quick actions Check status, pause automation during maintenance, or connect immediately
Performance mode (Windows) Scans and connects to the strongest Wi-Fi access point (BSSID) in your room

Quick setup for both platforms

Get up and running in under a minute with tailored installers for both operating systems.

Windows Inno Wizard Enter registration credentials during install with optional boot auto-start
macOS Drag-and-Drop Mount the DMG, drag to Applications, and authenticate seamlessly
