Troubleshooting VIT Hostel Wi-Fi & Loqin

Encountering connectivity drops, login failures, or captive portal errors? Follow these proven troubleshooting steps to restore seamless automated Wi-Fi access.

Captive Portal Fixes Session Drops Credential Errors

1. Wi-Fi Keeps Disconnecting or Asking for Portal Login

The VIT hostel captive portal system periodically terminates idle sessions or resets active client sessions when lease times expire.

  • Ensure Loqin is active: Verify that the Loqin icon is present in your Windows system tray or macOS menu bar. If it is paused, right-click/click and select Resume.
  • Check Device Session Limits: The campus network often enforces a limit on concurrent active sessions per student registration number (typically 2–3 devices). If your phone, tablet, and laptop are all connected, disconnect unused devices or log them out from the portal page.
  • Trigger Manual Reconnect: Select Connect Now from the Loqin tray/menu icon to trigger an immediate handshake with the captive portal.

2. "Invalid Credentials" or Authentication Rejection

If your registration credentials have changed or were mistyped during installation:

1

Check VTOP Password Expiration

VIT student Wi-Fi credentials frequently expire or require synchronized password resets with your VTOP student portal.

2

Update Stored Credentials in Loqin

Windows: Right-click the Loqin tray icon → Account Details → enter updated registration number and password.
macOS: Click the Loqin menu bar icon → Update Credentials.

3. Network Roaming & Switching Between Hostel Blocks

Moving your laptop from your hostel room to common rooms, dining halls, or academic blocks connects your Wi-Fi card to a new access point with a different local IP address.

  • Allow Roaming Handshake: Loqin automatically detects IP address changes and pings the new gateway within seconds.
  • Enable BSSID Performance Mode (Windows): If your laptop gets stuck on a weak access point from down the hallway, enable Performance Mode in the Loqin tray menu. Loqin will scan nearby BSSIDs and reconnect your adapter to the strongest Wi-Fi signal in your room.

4. SmartScreen or Gatekeeper Warnings During Setup

Commercial code signing certificates cost hundreds of dollars annually. As an open-source student utility distributed for free, Loqin binaries are unsigned:

Windows SmartScreen: Click More info on the blue pop-up, then click Run anyway. You can verify the integrity of the release against the open-source code on GitHub anytime.
macOS Gatekeeper: If macOS states "Loqin cannot be opened because it is from an unidentified developer", open Finder → Applications → Right-click Loqin → click Open → confirm Open.

5. Still Having Trouble? File a GitHub Issue

If your captive portal uses a custom URL or an unexpected authentication response, we can inspect the captive portal pattern and release an update.
