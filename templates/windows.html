Loqin for Windows Setup Guide

Learn how to install, set up, and get the most out of Loqin on Windows 10 and Windows 11. Enjoy seamless, zero-touch reconnection to VIT hostel Wi-Fi.

Windows 10 & 11 (64-bit) Inno Setup Installer Windows Credential Manager

1. Installation Walkthrough

Installing Loqin on Windows takes less than a minute. Follow these steps to configure your automated login:

1

Download the Windows Installer

Download Install_Loqin.exe directly from the Download Hub or GitHub Releases.

2

Run the Setup Wizard

Double-click the installer. If Windows SmartScreen prompts you with an unverified publisher notice, click More info and then Run anyway (Loqin is open-source software built by a student developer).

3

Enter Your Wi-Fi Credentials

During the setup wizard, input your VIT registration number and Wi-Fi password. Loqin immediately saves them directly into the native Windows Credential Manager.

4

Enable Auto-Start (Recommended)

Leave the "Launch at Windows startup" option checked so Loqin starts silently in the background every time you boot your laptop.

5

Check the Notification Tray

Once installation finishes, Loqin appears as an icon in your taskbar notification area (beside the clock). The status indicator turns green when authenticated.

2. How Windows Security & Credentials Work

Your login details are vital. Loqin uses Microsoft Windows' built-in security infrastructure rather than plain text configuration files:

  • Windows Credential Manager: Stored securely via the Python keyring library in the Windows Generic Credentials store.
  • User Isolation: Only processes running under your Windows user profile can retrieve the saved credential token.
  • Zero Cloud Sync: Loqin never uploads credentials to any remote server or third-party database. Authentication requests go strictly to the hostel captive portal gateway.
Need to update your Wi-Fi password? You can change your password anytime by right-clicking the Loqin tray icon and selecting Account Details, or by updating the entry in the Windows Credential Manager.

3. System Tray Controls & Performance Mode

Right-clicking the Loqin tray icon in the taskbar reveals quick controls:

  • Status: Shows current connection state (Connected, Authenticating, or Disconnected).
  • Connect Now: Forces an immediate captive portal re-authentication probe.
  • Pause / Resume: Temporarily stops automatic pings (useful during maintenance or when using mobile hotspot).
  • Performance Mode (Windows Exclusive): Scans nearby Wi-Fi access points and intelligently reconnects your Wi-Fi adapter to the BSSID with the highest signal quality in your hostel block.
  • Exit: Completely shuts down Loqin until your next boot.

4. Updating & Uninstallation

To update to a newer version of Loqin, simply download the latest installer and run it. The setup wizard automatically upgrades the existing binaries while preserving your saved configuration.

To uninstall Loqin, open Windows Settings → Apps → Installed Apps, search for Loqin, and click Uninstall. The uninstaller cleanly removes all application files and background startup registry entries.
