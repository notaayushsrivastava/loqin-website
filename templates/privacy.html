Loqin Security & Privacy

Privacy Policy

Last updated: November 12, 2026

1. Information the Application Uses

To authenticate you with the campus Wi-Fi provider, Loqin uses the registration credentials you input during initial setup. These credentials are stored strictly on your physical device within your operating system's native cryptographic vault (Windows Credential Manager on Windows, Apple Keychain Services on macOS).

Loqin does not transmit credentials to the developer, to third-party databases, or to any external cloud service. Credentials are used solely to generate authentication requests to the local network captive portal gateway.

2. Website Information & Tracking

This website does not require account creation, does not use tracking cookies, and does not run behavioral advertising beacons. Standard hosting and Content Delivery Network (CDN) logs may record technical HTTP request parameters (such as IP address, browser user-agent, and request timestamps) strictly for security monitoring and edge routing.

3. Data Sharing & Third Parties

Loqin never sells, rents, monetizes, or shares user data. When you click download links pointing to GitHub, your interaction is subject to GitHub's standard Privacy Statement.

4. Open Source Verification & Contact

The complete source code for Loqin is publicly inspectable under the GNU General Public License v3.0. You may verify security assertions directly on our GitHub repository or contact the maintainer through the issue tracker.
